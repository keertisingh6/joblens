# Indus Protect

A complete hackathon-ready IndusInd Bank general insurance prototype built with Next.js 15, React 19, TypeScript, Tailwind CSS, shadcn-style UI primitives, Framer Motion, React Hook Form, Zod, Recharts, Zustand, and Lucide Icons.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Features

- Live public prototype landing page
- Authentication and onboarding flows
- Mobile-first protection dashboard
- AI Saathi insurance assistant
- Policy management
- Claims and claim tracking
- Renewals, emergency hub, rewards, health, and vehicle modules
- Notifications, profile, settings, and dark mode
- Product strategy page mapped to the capstone brief
- Reusable typed components, local state store, accessible controls, charts, and forms
